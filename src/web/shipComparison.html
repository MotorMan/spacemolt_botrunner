Calculations
Cargo/sec = Cargo ÷ Jump Time (based on speed: 6=20s, 5=30s, 4=40s, 3=50s, 2=60s, 1=70s) Fuel/jump = (Tier × Speed) × Module Count Module Count = weapon_slots + defense_slots + utility_slots
Fuel cost assumes all module slots are filled. Use the module count filter to adjust.
